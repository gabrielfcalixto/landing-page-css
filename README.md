# GFCTech Form — Landing Page

Landing page para a GFCTech Form, plataforma de gestão de eventos e cursos.

## Tecnologias

- HTML5, CSS3, JavaScript
- intl-tel-input (campo de telefone internacional)

## Como usar

Abra `index.html` em um navegador ou sirva os arquivos estáticos com qualquer servidor HTTP.
